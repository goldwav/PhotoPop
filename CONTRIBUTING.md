# Contributing to PhotoPop

Thank you for helping build a trustworthy open-source image editor.

1. Open an issue before starting a large feature or document-format change.
2. Keep changes narrow and include tests for document mutations, file compatibility, and rendering behavior.
3. Never update visual baselines silently; explain the intended rendering change.
4. Preserve the renderer sandbox and typed preload boundary.
5. Add the MPL-2.0 header to new source files.

Run `pnpm verify` before submitting a change. Security issues should follow [SECURITY.md](SECURITY.md), not the public issue tracker.
