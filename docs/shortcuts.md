# Keyboard Shortcuts

These shortcuts describe the current Windows alpha. Single-key tool shortcuts do
not fire while focus is in a text field, number field, text area, or select
control.

## Files, history, and navigation

| Action | Shortcut |
| --- | --- |
| Command palette | `Ctrl+K` |
| New document | `Ctrl+N` |
| Open | `Ctrl+O` |
| Close document | `Ctrl+W` |
| Save | `Ctrl+S` |
| Save As | `Ctrl+Shift+S` |
| Undo | `Ctrl+Z` |
| Redo | `Ctrl+Shift+Z` |
| Copy merged image | `Ctrl+C` |
| Paste image as a layer | `Ctrl+V` |
| Fit canvas and reset rotation | `Ctrl+0` |
| Zoom in | `Ctrl++` or `Ctrl+=` |
| Zoom out | `Ctrl+-` |
| Close an open menu or dialog | `Esc` |

Within the command palette, use `Up` and `Down` to move, `Enter` to run the
highlighted command, and `Esc` to close it.

## Canvas navigation

| Action | Gesture |
| --- | --- |
| Pan | Hold `Space` and drag, or drag with the middle mouse button |
| Zoom at pointer | `Ctrl+mouse wheel` |
| Pan horizontally | `Shift+mouse wheel` |
| Pan vertically | `Mouse wheel` |

## Tools

| Tool | Shortcut |
| --- | --- |
| Move | `V` |
| Marquee | `M` |
| Lasso | `L` |
| Brush mask | `B` |
| Reveal mask | `E` |
| Fill | `G` |
| Gradient | `Shift+G` |
| Crop | `C` |
| Eyedropper | `I` |
| Text | `T` |
| Rectangle | `U` |
| Ellipse | `Shift+U` |

## Layers and text

| Action | Shortcut |
| --- | --- |
| Rename the focused layer | `F2` |
| Commit a layer rename | `Enter` |
| Cancel a layer rename | `Esc` |

Standard `Tab` and `Shift+Tab` navigation follow the visible workspace controls.
Shortcuts are intentionally conservative in the alpha so typing into editable
artwork or property fields does not unexpectedly change tools.
